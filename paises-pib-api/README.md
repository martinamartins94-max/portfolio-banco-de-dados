# Integração de dados de países com PIB

Projeto da disciplina de Coleta e Preparação de Dados (PUCRS).

- Consumo de API REST para coletar dados de países (código, nome, moeda, população, capital e área).
- Leitura de arquivo CSV com dados de PIB (1960–2021).
- Tratamento e integração das fontes em um único dataframe pandas.
- Exportação dos dados consolidados para CSV.
